# Проверки пакетов документов

Baseline: main `448fa283c2b9a8a0703f486ff6013ef179559fc4`. Изменения не включают production-миграцию/деплой и платные SMS.

- Prisma schema validation/generate: pass.
- 13 unit пакетов (34 вместе с регрессиями оплаты/редактора): случайные токены/коды, HMAC-связь, допустимые телефоны, явные действия, конфигурация, фиксированный Mobizon endpoint, неоднозначный результат и отсутствие повторной отправки.
- 21 интеграционная проверок реальной изолированной PostgreSQL: роли/tenant, обязательные пункты, неизменяемые байты PDF/хеши, конкурентное принятие, идемпотентное создание, точная ссылка сообщения, полный архив, изменение телефона/правил, отмена/отзыв/истечение, конкурентная платная попытка с тестовым провайдером, учёт неверных кодов, новый код/одноразовость, UNKNOWN без авто-повтора, составные FK; общий текст Kaspi/фото/пакета, устаревшая ревизия, точное содержимое запроса оплаты, публичные правила/конкурентная версия/история/отзыв.
- Компонентный браузерный стенд (не deployed E2E): реальные GuestAgreement/AgreementPanel + app CSS, синтетические fetch. 320/390/1440 guest, 320/1440 owner, OTP/UNKNOWN/expired. StrictMode, открытие без согласия, отдельные чекбоксы, явный owner callback, отсутствие горизонтального overflow и JS errors. Изображения просмотрены по одному; текст/CTA не обрезаны.
- Дополнительно: общий редактор 320/390/1440, нормальные и устаревшие данные (6 сценариев), блокировка передачи до повторной проверки; публикация правил 320/1440 только с отдельным подтверждением. Стенды компонентные, не полноценный deployed E2E.
- Schema gate: с включёнными обоими флагами полная fixture-схема проходит; отсутствие таблицы публичных правил блокирует выпуск при включённых пакетах, не блокирует при выключенных. Таблица восстанавливается в finally; production БД не использована.
- Линтер изменённых файлов: pass после исправлений.
- Полный TypeScript/build в этом частичном экспорте репозитория не доказан: `npm run build` завершился ошибкой: 63 missing-module ошибки из-за отсутствующих исходников других разделов. Полноценный checkout/CI и Preview обязательны. Отсутствие ошибок именно в новом модуле не равно успешной сборке приложения.
- Реальный API Mobizon/доставка/биллинг, native share iOS/Android, production DB, юридическая сила и независимый архив: НЕ проверены и НЕ заявлены готовыми.

Запуск на disposable loopback DB с применённой reviewed миграцией:

```
npx tsx --test src/lib/agreements/policy.test.ts
TEST_AGREEMENTS_DATABASE_URL=postgresql://.../fixture RUN_AGREEMENTS_DB_TESTS=1 npx tsx scripts/test-document-agreements.ts
```

Тест БД отказывается работать на не-loopback хосте или БД без `fixture` в имени. Удаляет только свои синтетические записи, не делает reset.
